# التقارير المالية وتصدير Excel

**الحالة:** موجود وشغّال، غير مؤجّل من ناحية الكود — فقط غير مطلوب حالياً بعقد الموبايل (`docs/new/openapi.yaml`).

## الموجود حالياً
- `GET /api/v1/owner/reports` — ملخص عام للتقارير.
- `GET /api/v1/owner/reports/properties` — تقرير حسب العقارات.
- `GET /api/v1/owner/reports/payments` — تقرير الدفعات.
- `GET /api/v1/owner/reports/contracts` — تقرير العقود.
- `GET /api/v1/owner/reports/maintenance` — تقرير الصيانة.
- `GET /api/v1/owner/reports/export` — تصدير Excel.

يعتمد المنطق على `src/lib/api/reports.ts` الذي تم تحديثه ليطابق أسماء الـ enums الجديدة (`unit_status`, `maintenance_status`, وقيمة `payment_status = 'due'` بدل `'pending'`).

## المطلوب لدمجها بعقد الموبايل مستقبلاً
- `docs/new/openapi.yaml` لا يحتوي أي مسار تقارير — يحتاج تأكيد من فريق الموبايل إذا كانت شاشات التقارير/التصدير موجودة أصلاً بالتطبيق قبل إعادة بنائها بالشكل المسطّح.
