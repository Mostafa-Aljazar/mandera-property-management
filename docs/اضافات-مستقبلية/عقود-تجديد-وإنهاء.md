# تجديد وإنهاء العقود

**الحالة:** موجود وشغّال، غير مؤجّل من ناحية الكود — فقط غير مطلوب حالياً بعقد الموبايل (`docs/new/openapi.yaml`).

## الموجود حالياً
- `POST /api/v1/owner/contracts/[id]/renew` — تجديد عقد قائم.
- `POST /api/v1/owner/contracts/[id]/terminate` — إنهاء عقد قبل موعده.
- `GET /api/v1/owner/contracts/[id]/file` — تحميل ملف العقد المرفق.

هذه الـ routes بقيت على مسارها القديم `/api/v1/owner/...` بدون أي تغيير وظيفي، فقط تم تحديث قيم الـ enums بداخلها (مثلاً `'vacant'` → `'available'`, `'pending'` → `'due'`) لتتوافق مع الـ migrations 015-018.

## المطلوب لدمجها بعقد الموبايل مستقبلاً
- إضافة مسارات مسطّحة تطابق شكل `docs/new/openapi.yaml` (مثلاً `POST /contracts/{id}/renew`, `POST /contracts/{id}/terminate`) بنفس نمط الـ response envelope الجديد (`openApiSuccess`/`openApiError`).
- التأكد أن فريق الموبايل فعلاً بحاجة هذه العمليات ضمن التطبيق (لم تكن مذكورة بالـ spec المرسل).
